# Calcuta

Текстовый редактор с живой математикой в стилистике редактора кода — вдохновлён [numbr.dev](https://numbr.dev), с рядом доработок. Тёмная тема, минималистичный интерфейс.

Всё приложение — один самодостаточный файл `index.html` (HTML + CSS + JS, без сборки и зависимостей). Просто открой его в браузере.

## Возможности

| Что | Как |
|---|---|
| **Живой расчёт** | Любое выражение считается на лету, результат — в правой колонке в овальной «пилюле». Клик по пилюле копирует чистое число; при наведении подсвечивается исходная строка. |
| **Математика** | `+ - * / ^ %`, скобки, суффиксы `k`/`M`, проценты (`100 + 25%`, `25% of 100`). Слова-контекст вокруг чисел игнорируются. |
| **Цвета операций** | Числа, участвующие в расчёте, — **небесно-голубые**; рабочие знаки (`+ − × ÷ ^ %`) — **оранжевые**; `=` и скобки приглушены. |
| **Переменные** | `бюджет = 500k` — подсветка фиолетовым, максимальный приоритет. Используются дальше по тексту. |
| **Агрегация** | `sum`/`сумм` складывает **непрерывный блок** результатов прямо над строкой (пустая строка обрывает блок), `avg`/`среднее` — среднее, `prev`/`пред` — предыдущий результат. |
| **Чекбоксы** | Команда `++ ` превращает строку в чекбокс. Клик по галочке → зелёный фон, бледный текст. Любая строка удаляется правым кликом (меню) или свайпом. |
| **Надзадачи и иерархия** | Строка с `//` — надзадача (фиолетовый). Всё под ней получает визуальный отступ; курсор «не чувствует» отступ — строка ведёт себя как обычная. Подзадачи белые. |
| **Тэги** | Задаются в боковом меню (текст + цвет), общие для всех документов. Подсветка тэга приоритетнее всего, кроме переменных. |
| **Даты** | Формат `дд.мм` (двузначный месяц) подсвечивается жёлтым. |
| **Числа** | Группировка тысяч (визуальная, тонкий пробел), десятичный разделитель — **запятая**: точка автоматически превращается в запятую (`3.14 → 3,14`, `1234.56 → 1 234,56`). При копировании пробелы убираются; при вставке любой формат (`1,234.56`, `1 234,56`, `рррр.кк`) приводится к `р ррр,кк`. |
| **Номера строк** | Узкий лаконичный столбец слева. Выделяй номера (клик, Shift, Ctrl или **перетаскиванием**) и задавай им цвет через правый клик. |
| **Наведение** | Строка под курсором слегка светлеет. Наведение на переменную/операцию подсвечивает её исходную строку. |
| **Документы** | Несколько документов в боковом меню: создание, переключение, удаление (с подтверждением). Стоковая страница **«Задачи»** не удаляется. Название редактируется в шапке. |
| **Поиск** | Строка поиска в боковом меню: совпадения в документе подсвечиваются жёлтым, счётчик `тек/всего`, навигация `↑`/`↓` (или `Enter`/`Shift+Enter`). Поиск идёт и по всем документам — у каждого показывается число совпадений. |
| **Автосохранение** | Документы (текст, название, цвета строк) и тэги хранятся в `localStorage`. |

## Приоритет подсветки

`Переменная (фиолетовый) → Тэг → Надзадача // (голубой) → Дата (жёлтый) → Число (голубой)`

## Синтаксис — коротко

```
// Бюджет проекта
доход = 2 500 000
налог = доход * 13%
чистыми = доход - налог
[ ] согласовать смету
[x] отправить отчёт 15.09
sum
```

## Заметки о формате чисел

- Десятичный разделитель — **запятая** (`12,5`). Точка в `дд.мм` трактуется как **дата** — это снимает конфликт «дата vs дробь».
- Число, введённое подряд (`2500000`), автоматически группируется тонким пробосом (`2 500 000`). Пробелы визуальные — копирование даёт `2500000`.

## Разработка / тесты

Логика движка вынесена в `window.__calcuta` (`analyze`, `evaluate`, `fmt`, `regroupText`, …), что позволяет юнит-тестировать её из headless-браузера без UI.
